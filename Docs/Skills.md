# Project skill register

Add one row for each skill when it is created, and update that row when its scope, location, status or validation changes. Link its modification report for the complete changed-file table and evidence. A skill folder existing on disk does not prove automatic discovery or successful behavioral validation. Use project-relative locations in public documentation; omit private installation paths and sensitive inputs.
